# 📚 Дневник МЭШ

> Удобный клиент для работы с электронным дневником Московской электронной школы (МЭШ).

---

## 🔑 Авторизация и получение токена

Для входа в приложение требуется персональный токен доступа. Выполните следующие простые шаги:

1. Перейдите на официальный портал [school.mos.ru](https://school.mos.ru/) и выполните вход в свой аккаунт.
2. После успешной загрузки страницы дневника откройте инструменты разработчика:
   * Нажмите клавишу **F12** (или сочетание `Ctrl + Shift + I` / `Cmd + Option + I` на macOS).
3. Перейдите на вкладку **Console** (Консоль).
4. Вставьте следующую команду и нажмите **Enter**:

   ```javascript
   copy(localStorage.getItem('token') || sessionStorage.getItem('token') || document.cookie)
   ```

5. Данные автоматически скопируются в буфер обмена. В скопированном тексте найдите токен: он начинается с `eyJ...` и заканчивается на `...QA3g`.
6. Вставьте полученную строку в поле авторизации и нажмите кнопку **Войти**:
